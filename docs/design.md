# デザイン計画

変換タブ（`src/app/`）とオプションページ（`src/options/`）の見た目と操作の計画。ライトテーマのみ。
手順は design-review `plan`（主題 → 4 要素 → 既視感照合）と tasteskill の app-screens（`draw.mjs --app`）に従った。

改訂 2（version 1.0.11 への GUI 指摘を受けた改訂）: 方針は「モダンで静かな業務ツール」。装飾は増やさず、
文字の段階・余白・部品の種類を揃え、枠線を減らし、操作結果を画面に返す。指摘の原文は
`../ask-user/table-format-converter/gui-feedback.md`。

## 1. 主題

| 項目 | 内容 |
|---|---|
| 主題 | 貼り付けた表を、別の表形式（Markdown / TSV / CSV / 罫線文字 / ASCII 罫線 / HTML / JSON）に書き換える作業台 |
| オーディエンス | チャット・ドキュメント・チケット・ターミナルの間で表を持ち運ぶ人。1 回数十秒の作業を 1 日に何度か繰り返す |
| 単一の目的 | 貼り付けた表を目的の形式で受け取り、コピーする |
| 画面の問い | 「この表は欲しい形式でどう出力されたか。コピーしてよいか」 |
| 最頻の操作 | 出力の「コピー」。緑の塗りの主ボタンはこれ（HTML 出力ではリッチコピー）だけ |

ヒーロー要素: 入力と出力の 2 つの等幅の作業欄を最初に、同じ高さで並べて見せる。見出しの大きな帯は置かない。

## 2. スタイルの選択

`draw.mjs --app --kind devtools --screens builder,settings --theme light --keep type` で 2 案が配られ、
`framed-sheet`（色付きの枠＋白い面）を選んだ。`achromatic-ledger` は金額・推移の画面向けで、この画面には推移も金額もない。
`--keep type` は CSP（`style-src 'self'`、外部接続なし）で Web フォントを読めないため、システムフォントを保つ指定。

改訂 2 では「1 枚の白いシート」をやめ、緑みのグレーの地の上に **入力・出力・プレビューの 3 枚の白い面（区画）** を置く。
区画どうしは線ではなく地色と余白で分ける（指摘の推奨方針 1・3）。

顔（face）: 表を印字してきたグリーンバー連続用紙（薄緑の帯の入った帳票）の緑みのグレーを地に、その用紙の濃い緑をアクセントにする。

表の罫は `#1f7a5a`、見出し行は `#c8ecd9`。図柄（表のグリッド＋双方向矢印）は変えない。

## 4. タイポグラフィ

書体は 2 役割: UI 書体（`system-ui, "Segoe UI", "Hiragino Sans", "Noto Sans JP", "Yu Gothic UI", sans-serif`）と、
入力欄・出力欄だけの和文等幅（`"BIZ UDGothic"`, `"MS Gothic"`, `"Noto Sans Mono CJK JP"` …）。
罫線表・Markdown の桁揃えは全角・半角の幅が 2:1 で揃う和文等幅でしか確かめられないため、作業欄だけを等幅にする。

| 段階 | トークン（サイズ / 行送り） | 太さ | 使う場所 |
|---|---|---|---|
| 区画見出し | `--fs-section 18px` / `--lh-section 26px` | `--fw-bold 600` | 入力・出力・プレビュー、オプションページの見出し |
| 製品名 | `--fs-brand 16px` / `--lh-brand 24px` | 600 | 上部バー |
| 本文 | `--fs-body 15px` / `--lh-body 22px` | `--fw-regular 400` | プレビューのセル、状態行、オプションの項目名 |
| 部品 | `--fs-control 14px` / `--lh-control 20px` | `--fw-medium 500`（ボタン）/ 400（ラベル・セレクト） | ボタン・セレクト・チェックのラベル、作業欄（等幅） |
| 補足 | `--fs-small 13px` / `--lh-small 18px` | 400、色は `--muted` | 判定結果・読み込み件数・設定の補足文・操作の説明 |

サイズは 13 / 14 / 15 / 16 / 18 の 5 段、太さは 400 / 500 / 600 の 3 段。数字は `tabular-nums`。

## 5. 余白と寸法

4px 基準: `--space-1 4` / `--space-2 8` / `--space-3 12` / `--space-4 16` / `--space-5 24` / `--space-6 32`。

| 用途 | 値 |
|---|---|
| ページの左右・上下の余白（上部バーも同じ値で端を揃える） | `--page-pad` 24px（600px 以下 12px） |
| 区画どうしの間隔（横・縦とも 1 値） | `--gap` 16px |
| 区画の内側余白 | `--card-pad` 24px（600px 以下 16px） |
| 区画内の行どうし（見出し行 → 操作行 → 作業欄） | 12px |
| 部品どうし・ラベルと部品 | 8px |
| 部品の高さ | `--control-height` 36px（ボタン・セレクト） |
| 列の操作ボタン | `--icon-button` 28px 四方、アイコン `--icon-size` 16px（「…」は `--icon-dot` 3px の太さ） |
| 角丸 | 区画 `--radius-card` 8px、部品 `--radius-control` 6px |

## 6. ボタンの 3 種類

全ボタンは高さ 36px・角丸 6px・文字 14px/500・アイコン 16px で揃え、縁は付けない。種類は地と文字の色だけで分ける。

| 種類 | 見た目 | ホバー | 当てはめるボタン |
|---|---|---|---|
| 主要 | `--accent` の塗り・白字 | `--accent-hover` | コピー、リッチコピー（1 画面に 1 つ） |
| 副次 | `--secondary` の地・墨字 | `--secondary-hover` | 貼り付け、ソースコピー、行列を入れ替え、編集を元に戻す、クリアを取り消す、候補の形式、既定値に戻す、列の操作 |
| 破壊的 | `--secondary` の地・朱字（赤は常時塗らない） | `--danger-soft` の地 | クリア |
| 静か（上部バー・メニュー） | 地なし・鼠字（メニューの項目は墨字） | `--secondary` の地（列を削除の項目だけ朱字で、ホバーは `--danger-soft` の地） | 設定（既定値）、詳細設定の開閉、列の操作メニューの項目 |

押せない状態（`disabled`）は地を `--raised`、文字を `--disabled-ink #687069`（薄地 4.7:1。押せなくても読める）にし、理由が画面から分かる状態でだけ使う
（出力が空の間のコピー、表が無い間の行列を入れ替え、編集が無い間の編集を元に戻す、入力が空の間のクリア、端の列での移動）。
影は浮くもの（列の操作のメニュー）にだけ `--shadow-float` を付ける。

## 7. レイアウト

散文: 48px の上部バー（製品マークと名前、右端に設定）の下に、入力・出力の 2 区画を横に並べ、その下に全幅のプレビュー区画を置く。
区画は白い面、間は 16px の地。各区画は「見出し行 → 操作行 → 補足の行 → 本体」の順で、見出し・形式セレクト・ボタン群を 1 行に詰めない。

```
┌ --ground #eef2ef ───────────────────────────────────────────────────────────────┐
│ [■] Table Format Converter                                      設定（既定値）    │ 48px
│ ┌ 入力（白い面） ──────────────────────┐ ┌ 出力（白い面） ────────────────────┐ │
│ │ 入力  入力をクリアしました。[クリアを取り消す]│ │ 出力  コピーしました。         [コピー] │ │ 見出し行（結果はここ）
│ │ 形式[自動判定 v]      [貼り付け][クリア] │ │ 形式[Markdown v] ☐桁を揃える 詳細設定∨ │ │ 操作行
│ │ 罫線文字の表（自動判定）・入力は 5 行 × 4 列│ │ 桁を揃える: 列の幅を空白で揃えます…     │ │ 補足の行（空でも 1 行分）
│ │ ┌──────────────────────────────────┐ │ │ ┌────────────────────────────────┐ │ │
│ │ │ 等幅の入力欄（高さはドラッグで変更）  │ │ │ │ 等幅の出力欄（読み取り専用）        │ │ │
│ │ └──────────────────────────────────┘ │ │ └────────────────────────────────┘ │ │
│ └──────────────────────────────────────┘ └────────────────────────────────────┘ │
│  [警告・エラーの状態行（黄・赤の枠。出ているときだけ）]                              │
│ ┌ プレビュー（白い面） ─────────────────────────────────────────────────────────┐ │
│ │ プレビュー  編集中の内容があります  1 つ前の状態に戻しました。 [編集を元に戻す][行列を入れ替え] │ │
│ │ ☑ 1 行目をヘッダーにする（自動判定）  セルをクリックして編集…入力欄は書き換わりません │ │
│ │ ┌ 四半期        [⋯] ┬ 売上（百万円）   [⋯] ┬ …（見出し行は薄地） ───────────────┐ │ │
│ │ │ Q1                 │ 120                  │  ← 横罫だけ、行ホバーで薄地         │ │ │
│ │ └─────────────────────────────────────── 利用できる横幅いっぱい ──────────┘ │ │
│ └──────────────────────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────────────────┘
```

- 左右に並ぶ間（961px 以上）は、2 区画が行（見出し行・操作行・補足の行・作業欄）を共有する（CSS subgrid）。
  詳細設定を閉じた状態では 2 つの作業欄の上端が一致する。操作行が折り返さないよう、入力のボタンは「貼り付け」と短くした
- 入力欄と出力欄の高さは、それぞれを独立にドラッグで変えられる。上の行は作業欄の高さで動かないので、ドラッグした欄の下端はカーソルに付いてくる。
  もう片方の欄は動かない
- 出力の操作行には「形式」と、その形式で最初に触る設定を 1 つだけ置く。残りは「詳細設定」（`<details>`、既定で閉じる）にまとめる。
  開くと操作行の中で下に広がる（その間は入力側の操作行の下が空く）
- 960px 以下では入力・出力を上下に積む（Q16）。600px 以下ではページと区画の余白を詰める
- プレビューの表は区画の幅いっぱいに広げ、列が多いときは区画の中で横スクロールする
- オプションページは同じ上部バーの下に、幅 720px の中央の白い面を 1 枚置き、設定の区画を見出し・余白・`--rule` の区切り 1 本で並べる（箱で囲まない）。
  意味の伝わりにくい項目には項目の下に 13px の補足文を置く

## 8. 列操作とプレビュー

- 列の操作は別の操作行に置かず、表の 1 行目（見出し行。見出しが無い表では 1 行目）の各セルの右端に、副次の地の 28px 四方の
  「列の操作」ボタン（「…」の記号）を 1 つだけ置く。押すと文字ラベル付きのメニュー（左へ移動・右へ移動・列を削除。列を削除は朱の文字）が開く
- メニューは `popover`（Chrome 114〜）で作り、Esc・外側のクリックで閉じる。フォーカスがメニューの外へ出たとき、ページや表がスクロールしたときも閉じる。
  開くと最初の押せる項目にフォーカスが移り、上下の矢印キーで項目を移れる。操作したあとは、操作した列（移動先・削除後の隣）の「列の操作」ボタンにフォーカスを戻す
- `title` と `aria-label` は、ボタンが「列の操作（N 列目）」、項目が「左へ移動（N 列目）」「右へ移動（N 列目）」「列を削除（N 列目）」
- 行の高さは 44px 前後、見出し行は `--raised` の薄地と 600 の太さ、行の区切りは `--rule` の横罫だけ（縦罫は引かない）
- 編集できることの示し方: セルのホバーで 1px の `--control` の輪郭とテキストカーソル、フォーカスで 2px の `--accent` の輪郭と `--accent-soft` の地。
  説明文で「編集は出力に反映され、入力欄は書き換わりません」と明示する。編集が 1 手以上あると「編集中の内容があります」を出す

## 9. 操作結果のフィードバック

成功の結果は、操作した区画の見出し行（`role="status"`・`aria-live="polite"` の 1 行。場所は常に確保してあり、文が出ても消えても他の要素は動かない）に出す。
警告・エラーは区画の間の状態行に、色と枠と文面で出し、自動では消さない。

| 操作 | 表示する場所と文 | 消え方 |
|---|---|---|
| 貼り付け（ボタン・Ctrl+V）、候補の形式の選択 | 入力の見出し行:「5 行 × 4 列を読み込みました（罫線文字の表）。」（見出し行も 1 行と数える） | 4 秒で消える |
| 入力（手入力を含む） | 入力の補足の行:「罫線文字の表（自動判定）・入力は 5 行 × 4 列」（入力の件数。プレビューで列を消しても変わらない） | 入力に合わせて更新 |
| コピー / リッチコピー / ソースコピー | 出力の見出し行:「コピーしました。」/「リッチテキスト（表）としてコピーしました。」/「HTML のソースをコピーしました。」 | 4 秒で消える |
| クリア | 入力の見出し行:「入力をクリアしました。」と［クリアを取り消す］。押すと入力・表モデル・編集履歴・見出しの指定をクリア前のまま戻し「クリアを取り消しました。」 | 次に入力するまで残る |
| プレビューの編集 | プレビューの見出し行:「編集中の内容があります」と［編集を元に戻す］（50 手まで 1 手ずつ）。戻すと「1 つ前の状態に戻しました。」 | 入力し直すと履歴ごと消える |
| 警告・エラー | 区画の間の状態行（黄・赤の枠） | 消えない（次の解析で更新） |
| 判定できない入力 | 候補パネルの文だけを見せる（状態行の同じ文は読み上げ用に視覚的に隠す） | 次の解析で更新 |

## 10. シグネチャ要素

プレビュー表の見出し行の下に引く 2px の罫（`--control`）。罫線文字の表のヘッダー区切り（`├──┼──┤`）や
Markdown の `| --- |` 行と同じ位置に同じ意味の線を置き、「ここまでが見出し」をプレビューでも同じ形で示す。
改訂 2 で、緑を主要操作・フォーカス・選択状態に限るため、色を緑から鼠に変えた。

## 11. 既視感パターンとの照合

| パターン | 該当 | 理由 |
|---|---|---|
| クリーム背景 + セリフ体 + テラコッタ | なし | 地は緑みのグレーと白、書体は UI ゴシック、アクセントは緑 |
| 暗い背景 + ネオン | なし | ライトのみ |
| 新聞風レイアウト + ヘアライン罫 | なし | 区画は面で分け、罫は表の行の区切りにだけ引く |
| tasteskill の app 画面の禁止事項（グラデーション・影・アイコン入りの色付き四角・紫系アクセント・大見出し） | なし | 影は使わない。見出しは最大 18px |

差し替えテスト: 主題を別の製品に替えると、グリーンバー緑の地と見出し下の 2px 罫（表のヘッダー区切りの写し）は意味を失う。

## 12. 実装の注意

- 色・余白・文字・角丸は `src/app/tokens.css` の CSS カスタムプロパティに集約し、両ページから読み込む。各ページの CSS は直値を持たない
- 余白の衝突を避けるため、要素に外側の `margin` を持たせず、親の `gap` で間隔を決める
- 360px 幅まで横スクロールなし（プレビュー表と作業欄の内部スクロールは可）
- フォーカスは `:focus-visible` に 2px のアクセントの輪郭を必ず出す。テキスト欄は輪郭を縁の上に重ねて線 1 本にする
- `prefers-reduced-motion: reduce` ではホバーの遷移を止める
- 状態行・候補パネル・プレビューの省略表示の文は `overflow-wrap: anywhere` で折り返す。プレビューのセルは `white-space: pre`（セル内の改行・連続空白は表示し、幅では折り返さない）
