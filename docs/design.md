# デザイン計画

変換タブ（`src/app/`）とオプションページ（`src/options/`）の見た目の計画。ライトテーマのみ。
手順は design-review `plan`（主題 → 4 要素 → 既視感照合）と tasteskill の app-screens（`draw.mjs --app`）に従った。

## 1. 主題

| 項目 | 内容 |
|---|---|
| 主題 | 貼り付けた表を、別の表形式（Markdown / TSV / CSV / 罫線文字 / ASCII 罫線 / HTML / JSON）に書き換える作業台 |
| オーディエンス | チャット・ドキュメント・チケット・ターミナルの間で表を持ち運ぶ人。1 回数十秒の作業を 1 日に何度か繰り返す |
| 単一の目的 | 貼り付けた表を目的の形式で受け取り、コピーする |
| 画面の問い | 「この表は欲しい形式でどう出力されたか。コピーしてよいか」 |
| 最頻の操作 | 出力欄の「コピー」。主ボタンはこれ 1 つに限る |

ヒーロー要素: 入力と出力の 2 つの等幅の作業欄を最初に、同じ高さ・同じ上端で並べて見せる。見出しの大きな帯は置かない。

## 2. スタイルの選択

`draw.mjs --app --kind devtools --screens builder,settings --theme light --keep type` で 2 案が配られ、
`framed-sheet`（色付きの枠＋白いシート）を選んだ。理由: 作業台は「枠（道具）と紙（作業面）」の二層で読めるのが自然で、
`achromatic-ledger` は金額・推移の画面向けで、この画面には推移も金額もない。
`--keep type` は CSP（`style-src 'self'`、外部接続なし）で Web フォントを読めないため、既存のシステムフォントを保つ指定。

顔（face）: 枠の色を製品の世界から取る。表を印字してきたグリーンバー連続用紙（薄緑の帯の入った帳票）の緑みのグレーを枠に、
その用紙の濃い緑をアクセントにする。シートは白のまま。

## 3. カラー（トークン名 / 16 進値 / 役割）

| 名前 | トークン | 値 | 役割 |
|---|---|---|---|
| 帳票の地 | `--ground` | `#f3f6f4` | 枠（上部バーと余白）。緑みのグレー |
| 紙 | `--surface` | `#ffffff` | 作業シート・入力欄・出力欄 |
| 薄地 | `--raised` | `#f6f8f7` | 候補パネル、セルのホバー、無効なボタンの地 |
| 墨 | `--text` | `#17201b` | 本文（白地で 16.7:1） |
| 鼠 | `--muted` | `#566059` | 補助文・ラベル（白地で 6.5:1、枠地で 6.0:1） |
| グリーンバー緑 | `--accent` | `#1f7a5a` | 主ボタン・フォーカス・プレビュー見出しの下罫・チェック（白地で 5.3:1） |

線は 3 段: `--border #dfe5e1`（シート・パネルの縁）、`--rule #edf1ee`（パネル内の区切り）、`--control #869089`（入力欄・ボタンの縁。部品の境界として白地 3.3:1・薄地 3.1:1・枠地 3.0:1 を満たす値）。
状態色: 警告 `#fffbeb` 地 / `#fde68a` 縁 / `#92400e` 字、エラー `#fff1ef` 地 / `#f5c2bb` 縁 / `#9b1c1f` 字。
アクセントの淡色 `--accent-soft #e4f1eb`（編集中のセル）。ボタンのホバー `--hover #e6ece8`（白地から 1 段濃く）。押せない列操作ボタンの記号 `--disabled-ink #b9c2bc`（有効時の `--muted` と区別でき、存在は見える薄さ）。ダークテーマは持たない（`color-scheme: light`）。

拡張アイコン（`public/icons/icon.svg`）も同じ色相（約 159°）にそろえ、青系（色相 190〜270°）のアイコンが並ぶツールバーで埋もれないようにする。地は 16px のツールバーで明暗どちらの背景からも浮くよう UI のアクセントより一段明るい `#23966c`（白地 3.7:1、`#202124` 地 4.3:1）、表の罫は `#1f7a5a`、見出し行は `#c8ecd9`。図柄（表のグリッド＋双方向矢印）は変えない。

## 4. タイポグラフィ

| 役割 | 書体 | サイズ / 太さ |
|---|---|---|
| 表示・本文・ラベル | システムの UI 書体（`system-ui, "Segoe UI", "Hiragino Sans", "Noto Sans JP", "Yu Gothic UI", sans-serif`） | 製品名 16/600、区画見出し 16/600、本文 14/400、補助 12/400 |
| ユーティリティ（入力欄・出力欄） | 既存の等幅スタック（`"BIZ UDGothic"`, `"MS Gothic"`, `"Noto Sans Mono CJK JP"` …） | 14、行送り 1.5 |

ペアリングの理由: 罫線表・Markdown の桁揃えは全角・半角の幅が 2:1 で揃う和文等幅でしか確かめられないため、作業欄だけを等幅にし、
画面の他の部分は OS の UI 書体で道具らしく静かにする。サイズは 12 / 14 / 16 の 3 段、太さは 400 / 500 / 600 の 3 段に限る。
数字は `tabular-nums`。

## 5. 余白スケール

4px を基準に `--space-1 4` / `--space-2 8` / `--space-3 12` / `--space-4 16` / `--space-5 24` / `--space-6 32`。

- 区画どうしの間隔（入力と出力の間、作業欄とプレビューの間）は `--space-5`（24px）の 1 値に統一する
- 区画内（見出し行 → 出力オプション → 作業欄）の間隔は `--space-3`（12px）、ボタンどうし・ラベルと部品の間は `--space-2`（8px）
- シートの内側余白は 24px（600px 以下では 16px）、枠からのシートの差し込みは 8px
- 上部バーの左右の余白は「差し込み 8 + 縁 1 + 内側余白 24 = 33px」（600px 以下では 16px）。製品名と設定ボタンを、シート内の見出し・作業欄と同じ左右の端に揃える
- 操作部品の高さは 32px（`--control-height`）に統一し、プレビューの列操作ボタンだけ 24px（WCAG 2.2 のターゲット最小値）

## 6. レイアウト

散文: 48px の上部バー（製品マークと名前、右端に設定）と左右下 8px の枠が 1 つの緑みのグレーで L 字に囲み、
その内側の白いシートに入力・出力の 2 列と、全幅のプレビューを縦に積む。

```
┌ --ground #f3f6f4 ────────────────────────────────────────────────────────┐
│ [■] Table Format Converter                              設定（既定値）    │ 48px
│ ┌ --surface #fff・1px #dfe5e1・角丸 16 ────────────────────────────────┐ │
│ │ 入力 形式[自動判定 v] 判定: 罫線文字の表 [貼り付け][クリア] │ 出力 形式[罫線文字 v] [コピー] │ │
│ │ ┌────────────────────────────┐             │ ☑ヘッダー（自動） 線種[v] ☑行罫  │ │
│ │ │ 等幅の入力欄               │             │ ┌──────────────────────────┐    │ │
│ │ │ （出力オプションの行と     │             │ │ 等幅の出力欄 360px        │    │ │
│ │ │  出力欄の行にまたがる）     │             │ │ 白地・弱い縁＝読み取り専用 │    │ │
│ │ └────────────────────────────┘             │ └──────────────────────────┘    │ │
│ │ [候補パネル（判定できないときだけ）]                                       │ │
│ │ [状態行: 警告は黄の枠、エラーは赤の枠、コピー完了は灰色の 1 行]             │ │
│ │ ─────────────────────────────────────────────────────────────────── │ │
│ │ プレビュー  [行列を入れ替え]  セルをクリックすると編集できます…             │ │
│ │  ←→×  ←→×  ←→×                                                       │ │
│ │  四半期 │ 売上 │ …   ← 見出し行の下に 2px の緑の罫                         │ │
│ │  Q1     │ 120  │ …                                                      │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
```

961px 以上では 2 列が行を共有する（1 行目 = 見出し行、2 行目 = 出力オプション、3 行目 = 作業欄）。入力欄は 2〜3 行目にまたがって伸びるので、
出力オプションが何行に折り返しても入力側に空きができず、2 つの作業欄の下端が揃う。見出し行は行の上端に揃える。
960px 以下では入力・出力を上下に積み（Q16）、600px 以下では枠が消えてシートが画面全体になる。
オプションページは同じ上部バーとシートを使い、幅 720px の中央の列に設定の区画を縦に並べる。区画は箱で囲まず、
区画見出し（`legend`）・区画間の余白・区画の間の `--border` の罫 1 本でまとめる（`fieldset` / `legend` の構造は保つ）。
セレクトを伴う行はラベルを左・部品を右に置き、480px 以下ではラベルの下に部品を置く。

## 7. シグネチャ要素

プレビュー表の見出し行の下に引く 2px のグリーンバー緑の罫。罫線文字の表のヘッダー区切り（`├──┼──┤`）や
Markdown の `| --- |` 行と同じ位置に同じ意味の線を置き、「ここまでが見出し」をプレビューでも同じ形で示す。
「1 行目をヘッダーにする」を切り替えると、この罫が付いたり消えたりする。

## 8. 既視感パターンとの照合

| パターン | 該当 | 理由 |
|---|---|---|
| クリーム背景 + セリフ体 + テラコッタ | なし | 地は緑みのグレーと白、書体は UI ゴシック、アクセントは緑 |
| 暗い背景 + ネオン | なし | ライトのみ |
| 新聞風レイアウト + ヘアライン罫 | なし | 2 列の作業欄とプレビュー。罫は表そのものにだけ引く |
| tasteskill の app 画面の禁止事項（グラデーション・影・アイコン入りの色付き四角・紫系アクセント・大見出し） | なし | 影は使わず 1px の縁と 1 段のトーン差だけで区切る。見出しは最大 16px |

差し替えテスト: 主題を別の製品に替えると、グリーンバー緑の枠と見出し下の 2px 罫（表のヘッダー区切りの写し）は意味を失う。
したがって主題に固有と判断した。

## 9. 実装の注意

- 色・余白・文字・角丸は `src/app/tokens.css` の CSS カスタムプロパティに集約し、両ページから読み込む。各ページの CSS は直値を持たない
- 余白の衝突を避けるため、要素に外側の `margin` を持たせず、親の `gap` で間隔を決める
- 360px 幅まで横スクロールなし（プレビュー表と出力欄の内部スクロールは可）
- フォーカスは `:focus-visible` に 2px のアクセントの輪郭を必ず出す。テキスト欄は輪郭を縁の上に重ねて 2px の線 1 本にする。編集中のセルは内側に輪郭を出す
- 出力欄は入力欄と同じ白地にし、読み取り専用であることは入力欄（`--control`）より弱い縁（`--border`）で示す
- 状態行・候補パネル・プレビューの省略表示の文は `overflow-wrap: anywhere` で折り返し、空白のない長い文でもはみ出さない
- プレビューのセルは `white-space: pre`（セル内の改行・連続空白は表示し、幅による折り返しはしない。はみ出す分はプレビューの横スクロール）。列操作の行はセルと同じ左右の余白で見出し文字と左端を揃える
- `prefers-reduced-motion: reduce` ではホバーの遷移を止める
- 状態: ホバー（ボタンは `--hover`、セルは `--raised`）、無効（文字を `--muted` に落とし、カーソルを既定に戻す）、警告・エラー（色＋縁＋文面）、
  プレビューの空状態（枠を保って 1 文）、プレビュー省略時（同じ枠で 1 文）
