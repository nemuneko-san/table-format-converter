# Table Format Converter

いろいろな表記法の表を貼り付けると、選んだ形式に相互変換して表示・コピーできる Chrome 拡張です。

## 導入

1. `npm install` → `npm run build` で `dist/` を作る（配布用の zip `table-format-converter.zip` も同時に作られます）。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」で `dist/` フォルダを選ぶ。

zip を受け取った場合は、展開したフォルダを手順 3 で選んでください。Chrome 116 以降が必要です。

## 使い方

1. ツールバーの拡張アイコンを押すと、変換タブが開きます（開いていればそのタブに切り替わります）。
2. 左の入力欄に表を貼り付けます（Ctrl+V、または「貼り付け」ボタン）。貼り付けると画面の右下に「N 行 × M 列を読み込みました」と通知（3 秒で消えるトースト）が出ます。「クリア」で入力を消したときは、クリアボタンの近くに出る「クリアを取り消す」で、プレビューの編集も含めてクリア前の状態に戻せます。入力欄と出力欄は、右下をドラッグすると高さを変えられます。
3. 右の出力欄に、選んだ出力形式へ変換した結果がすぐに表示されます。「コピー」でクリップボードへコピーし、画面の右下に「コピーしました」と通知が出ます（コピーに失敗したときは赤い通知と、消えないエラー表示が出ます）。出力の形式ごとの細かい設定（行の間の罫線・曖昧幅の文字・JSON の数値）は「詳細設定」ボタンで開く小さな面で変えられます（Esc か外側のクリックで閉じます）。
   - HTML 出力では「リッチコピー」（Excel・Google ドキュメント・Word などに表として貼り付く）と「ソースコピー」（HTML ソース）を選べます。
4. 入力形式は自動で判定します。判定できないときは候補が表示されるので、形式を選んでください。入力欄上のセレクトで手動指定もできます。
5. 下のプレビューでは、セルの直接編集・列の移動と削除（1 行目の各セルにある「…」の「列の操作」ボタンを押すと、左へ移動・右へ移動・列を削除を選べます）・行列の入れ替えができます。編集は出力に反映されます。入力欄は書き換えません。プレビューの「編集を元に戻す」で、編集を 1 手ずつ（最大 50 手）戻せます。出力形式や線種などの出力の設定を変えても編集は残ります。入力欄の編集・貼り付け、入力形式の変更、前処理の設定の変更をすると、入力から作り直すので編集は破棄されます。
6. プレビューの「1 行目をヘッダーにする」で、ヘッダーの自動判定を上書きできます。
7. 列数が揃っていない行は空セルで補い、警告を表示します。表の前後にある説明文を除外したときは、除外した行数を表示します（CSV / TSV では、空行で区切られていない行は表の一部として扱います。コードフェンス（```）で囲んだ表を貼り付けた場合は、フェンスの内側だけを表として読み、外側の文章は除外します。フェンスの中身が表でない（コマンドやコードの）場合は、フェンスの外にある表を読みます）。変換中にエラーが起きたときはエラーを表示し、出力形式を変えるなどして変換できればエラー表示は消えます。

右上の「設定（既定値）」から、線種・行間罫線・曖昧幅・Markdown の桁揃え・CSV の区切り文字・HTML のスタイル・JSON の構造と数値型・貼り付け時の前処理の既定値を変更できます。最後に選んだ出力形式と、直近の入力内容は次回も復元されます。

## 対応形式（入力・出力とも）

| 形式 | 例 |
|---|---|
| Markdown（GFM のパイプ表） | `| a | b |` / `| --- | ---: |` |
| TSV（スプレッドシートからの貼り付け） | タブ区切り。引用符で囲んだセル内のタブ・改行も扱う |
| CSV | 入力はカンマ / セミコロン / パイプを自動判定。出力の区切り文字は設定で選ぶ |
| 罫線文字の表 | `┌─┬┐ │ ├┼┤ └┴┘`。出力は単線 / 太線 / 二重線 / 角丸 |
| ASCII 罫線の表 | `+---+` と `|` |
| HTML の table | colspan / rowspan は先頭セルに値、残りは空セル |
| JSON | オブジェクト配列 / 2 次元配列 |

罫線表の桁揃えは、全角 2・半角 1・絵文字 2・結合文字 0 として計算します。曖昧幅の文字（— × ○ ※ → 罫線文字など）を幅 1 と 2 のどちらで数えるかは設定で切り替えます（既定は 2）。

## プライバシー

この拡張は**データを外部に送信しません**。入力した表・変換結果・設定はすべてブラウザ内で処理し、保存先は Chrome の拡張ストレージ（設定は `chrome.storage.sync`、直近の入力は `chrome.storage.local`）だけです。Web ページへのスクリプト注入やサイトへのアクセス権限も持ちません。拡張のページには Content Security Policy（`connect-src 'none'` など）を設定しており、外部への接続や外部画像の読み込みはブラウザが禁止します。

使用する権限:

- `storage`: 設定と直近の入力の保存
- `clipboardRead`: 「貼り付け」ボタン（クリップボードから読み込む）
- `clipboardWrite`: 「コピー」ボタン

## 開発

```bash
npm install
npm test            # Vitest（happy-dom）
npx tsc --noEmit    # 型チェック
npm run build       # 型チェック → dist/ 生成 → zip 生成
npm run icons       # public/icons/icon.svg から 16/48/128 PNG を生成
node scripts/gen-eaw.mjs <EastAsianWidth.txt>  # 文字幅データ src/lib/eaw-data.ts を再生成
```

- 仕様: `docs/spec.md`
- 変換ロジック（DOM 非依存の純粋関数）: `src/lib/`（パーサ → 共通の表モデル → シリアライザ）
- 変換タブ: `src/app/`、オプションページ: `src/options/`、service worker: `src/background/`
- コミットのたびに共有 hook が `manifest.json` の version を自動で +1 します（`../README.md` 参照）。コミット後は `npm run build` で `dist/` と zip を作り直してください。
